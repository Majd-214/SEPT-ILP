A lab page is interactive because of things a rich-text editor is entitled to throw away. This page carries one of each, and reports which ones are still here.

How to run it

  1. Put this file in a sandbox course beside the unzipped course site — the same folder as index.html, so assets/ sits next to it — and open it as a content topic. Every row should read present: that is the baseline. Press Save this as the baseline.
  2. In the topic's dropdown choose Edit HTML (or Edit, then the </> source view).
  3. Change nothing. Press Save or Update.
  4. Reload this page. Any row that now reads gone is something the editor stripped on a save that changed nothing.
  5. Repeat once more, this time typing a word into a paragraph before saving. Some editors only rewrite the document when it is actually dirty.

Rows are judged against the page's own DOM, so the answer holds however Avenue chose to store the file.
