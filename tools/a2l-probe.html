What this page cannot tell you

  1. Are the D2L HTML templates installed? Content → Upload/Create → Create a File. Look for a Select a Document Template button. If it is missing or the list is empty, nobody has installed them.
  2. Is Creator+ licensed? Open any HTML editor. Look for an Insert Element button (accordions, tabs, flip cards). Present = licensed.
  3. Is H5P available? In the editor, Insert Stuff — look for H5P, or check Course Admin → External Learning Tools.
  4. Do Arithmetic quiz questions do what we need? Quizzes → new quiz → add an Arithmetic question. Check you can set tolerance (units or percent), significant figures, and units. This is the native replacement for our auto-marking.
  5. Can you gate one topic behind another? On any topic → Edit → Add release condition → based on a quiz score or checklist. This is the native replacement for our step-by-step locking.
  6. Is Content Sandboxing on? Course Admin → Course Offering Information → look for Enable Content Sandboxing. (The row below infers this too.)
